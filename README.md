# Manual Foster Vase

## what do you need:
### Hard ware
- NodeMCU ESP8266
- water-level sensor
- temperature sensor
- LEDs / NeoPixel LED strip
- Physical button

### Soft ware
- Arduino IDE
- Board package (ESP8266 board package)
- Library
- LED library, (Adafruit NeoPixel)
- Adafruit IO
- Weather API
- Wi-Fi network
